### 🚀 About Me

I started with a B.Sc. in Physics, then moved into a B.Tech in Information Technology at the University of Calcutta — so a lot of how I approach a problem still comes from that background: model it, test it, break it, fix it. These days that turns into full-stack web apps, small AI-integrated tools, and the occasional microcontroller build.

- 🎓 B.Sc. in Physics, currently completing B.Tech in Information Technology at the University of Calcutta
- 🌏 Based in Kolkata, West Bengal, India
- 💻 Enthusiast of full-stack MERN development, Machine Learning & Applied AI, and exploring new technologies
- 💡 Physics graduate leveraging analytical modeling to write clean, optimized code
